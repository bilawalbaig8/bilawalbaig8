## Send this to your personal GPT

Prepare a coordinated asset set for Bilawal Baig, AI + Game Pipeline Lead, working in technical art, animation, AI-assisted game production and playable ads. Visual direction: a game development studio workbench, isometric scene geometry, tactile game assets and subtle animation. Palette: deep navy #101d30, slate #182a42, sky blue #71b7ff, warm amber #ffc57a, off-white #edf4ff. Keep images readable at small size. No baked-in names, text, company logos or fake app interfaces; text will be added separately. Keep visual subjects toward the right side of wide banners to allow text on the left.

1. studio-key-art.webp — 1920 × 720. An original isometric miniature game-development workspace, low-poly game props, monitor, rig controls, a small playable world on the desk. Reserve the left 55% for text. Also supply a PNG master.
2. studio-loop.gif — 1280 × 480, seamless 4–6 second loop, 12–18 fps, target under 5 MB. Very gentle object rotation, a light moving through a production pipeline, or a game scene assembling. No flashing or camera shake. Supply an MP4 master as well.
3. ai-production.gif — 960 × 540, 4–8 seconds. Use provided REAL footage showing concept → asset → Unity/game result from Kittydoku, Toyland Go! or Mall Bus Jam. Label project and my role in the accompanying notes, not inside the image.
4. playable-ads.gif — 960 × 540, 4–8 seconds. Use provided REAL playable-ad footage showing a clear interaction and result. MP4 master plus optimized GIF under 5 MB.
5. technical-art.gif — 960 × 540, 4–8 seconds. Use provided REAL rigging, animation, shader, or tools footage from a project I worked on. MP4 master plus GIF under 5 MB.
6. project-covers/ — three 1280 × 720 WEBP or PNG stills for the above showcases. Match framing, lighting and palette while preserving actual game artwork.

Prioritize 3, 4 and 5: actual work makes the profile distinctive. The generated studio art is optional. Do not invent footage if source material is missing; return a list of source clips needed.

Videos are source masters. The README will use optimized GIFs or still thumbnails linking to videos/demos. No additional image is needed for the contribution city; GitHub Actions generates it from real contribution data.
