# Artwork direction

Approved palette: navy **#19232D**, off-white **#EEF0EE**, slate **#8EA6B8**. Body text uses **#B8C7D3** for contrast. Raster edits were made with GPT built-in image generation; code renders native text, SVG decoration, and layered animation without recoloring the raster artwork. Original assets remain retained in Git.

Lock Bilawal's recognizable face, dark wavy hair, glasses, neat beard, charcoal hoodie, red/black headphones, and friendly expression. Keep hands, pose, and intended framing consistent. Use neutral daylight and natural material colors, with no orange/purple studio lighting or luminous surround. Green game scenery and restrained red headphone details are intentional.

- **hero-approved.png:** approved direction reference; preserve the left-text/right-character hierarchy, white name, slate role, and generous spacing. This reference is retained separately from the native animated composition.
- **hero-character.png:** transparent character cutout, turned and gazing left toward the text, holding the game-world cube. Preserve recognizable identity, hand/cube relationship, and left-facing gaze. Native text stays fixed while the character gently bobs.
- **avatar.png:** neutral portrait illustration for the About panel; preserve identity and crop compatibility, with natural skin and charcoal clothing.
- **meditation.png:** transparent full cross-legged meditation pose; retain both open hands, knees, shoes, face, and headphones. The renderer adds restrained slate floor rings and independently floating tool tokens.
- **contact.png:** wide front-facing studio scene with complete relaxed seated pose and chair visible; neutral daylight, navy/charcoal surfaces, natural green plants and game monitors. Fit the full artwork rather than cropping it.
- **partnership.png:** neutral version of the original wide partnership artwork; retain all existing visual information and text while removing purple/orange lighting.

Generation caveats: transparent images can include soft translucent spill around the character; judge them composited on the navy background, not only on a black transparency preview. Future edits should preserve likeness and gaze rather than simply mirroring the whole composition. Keep written profile copy as native text where possible. The original real photographic portrait remains the dashboard ID image.
