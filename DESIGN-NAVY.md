# Navy/slate profile

The approved direction uses navy backgrounds (#19232D), off-white headings (#EEF0EE), slate accents (#8EA6B8), and brighter muted body text (#B8C7D3). Decorative orange/purple gradients, starfield dots, and hero particles have been removed. Natural artwork colors, red headphones, and green game-world scenery remain.

The supplied generated artwork is retained in `assets/navy/`. Hero, avatar, meditation, contact, and partnership images were created or relit using image generation. Raster artwork is not recolored by the renderer. The original photographic dashboard portrait is retained.

`scripts/navy/build.cjs` is the local renderer; see its README for dependencies and commands. Hero text stays fixed while the character gently bobs. The toolkit character and tokens float independently; the ID lanyard swings; contact glints move subtly. Each GIF loops indefinitely over 72 frames and six seconds. Matching PNGs provide static fallbacks, and `STATIC.md` contains a visibly linked static profile view.

Profile prose, project links, and city automation remain intact. A factual entry for the public github-profile-studio skill repository was added. The existing contribution city continues using its blue/green palettes and daily workflow. This renderer never commits or pushes changes.
